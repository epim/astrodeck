# Find and frame a target

These steps use the alternative interface. Open `#/next`, then go to **SKY** (`#/sky`). The server root opens the classic interface; see [Interface routes](next-ui.md) if your screen looks different.

<a id="searching-for-a-target"></a>

<a id="sky-atlas"></a>

## Search for a target

1. Open the target list at `#/sky/targets`. Search by name in **Search the target catalog**, then select a result to aim the finder at it.

2. Check the target and observing window against your saved site and horizon. If site placement is unknown, finish [Site and locations](site-and-locations.md) before trusting the local sky view.

3. Select **ATLAS** to inspect the map. Select **FRAME** to frame the current target or patch of sky; an unavailable action explains what is missing.

## Match the camera field

1. Configure telescope and camera optics first. In framing mode, use **MATCH CAMERA** to match the view to one camera field, or **FIT OBJECT** when the catalogue supplies an object size.

2. Drag the sky to move the framing centre. Set **PA** or turn the rotation dial. This plans a camera angle; without a rotator, the camera must be turned by hand before the run.

3. Choose a grid in the framing card, then select **SEND TO FLOW WIZARD** to carry its centre, angle, grid and overlap into a flow. Review the resulting stages before running it. See [Flows and mosaics](flows-and-mosaics.md) for the saved flow editor.

## Find an observing window

The target list ranks suggestions for tonight and provides filters. Treat the ranking as a planning aid: review the target, local horizon and current conditions before starting a run.

## Use the sky view offline

The schematic sky can be used offline. Survey imagery is separate: no DSS2 tile pack is distributed with releases. An operator can fetch survey tiles from inside Atlas for personal use; imagery needs the relevant attribution and is not a guarantee of offline coverage. This guide contains no survey screenshots.
