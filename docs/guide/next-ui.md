# Choose an interface

The server root opens the classic interface. `#/next` opens the alternative interface at the sky screen. Both interfaces use the same server and equipment; changing the interface is not a separate simulator or a second rig.

## Open the page you need

1. Keep the server address and port, and replace its fragment with `#/next`.

2. Navigate with **SKY**, **WEATHER**, **SESSION**, **RIG**, **MONITOR** and **SETTINGS**. The available hubs depend on your account capabilities.

3. Use the following fragments for direct links. `next` is an entry alias, not a path prefix: use `#/session/flows`, not `#/next/session/flows`.

| Task | Alternative interface |
| --- | --- |
| Find and frame a target | `#/sky` |
| Forecast | `#/weather/conditions` |
| Flow library | `#/session/flows` |
| Current run | `#/session/now` |
| Sessions | `#/session/gallery` |
| Equipment | `#/rig/devices` |
| Manual capture | `#/rig/capture` |
| Live monitor | `#/monitor/live` |
| Event log | `#/monitor/log` |

4. Return to the classic interface with `#/classic`. An explicit classic page link is `#/classic/capture` or `#/classic/monitor`. A bare `#/monitor` selects the alternative hub.

## Phone and desktop

On a phone, opening a flow shows its stage list, including stage editing and tap-to-wire controls. The pannable canvas and the plan editor require a tablet or desktop.

A locked control can explain why it cannot act. Read that reason before changing equipment or permissions. Browser Back closes an open sheet or returns to the preceding route.
