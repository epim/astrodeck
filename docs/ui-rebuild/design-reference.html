AstroDeck Native-parity control surface · design reference

The instrument

A control surface you'd trust with a mount at 2 a.m.

AstroDeck runs unattended for hours, driving expensive gear in the cold and the dark. So the interface behaves like a precision instrument, not an app: a calm dark field, telemetry set in tabular figures that never jitter, state you read at a glance, and one confident accent — a phosphor aqua, the color of a guide star locked on. Two moments earn motion: an autofocus curve drawing itself as the sweep runs, and a polar-alignment error vector visibly converging as you turn the knobs. Everything else stays still, so those two moments land.

01 · Design system

The vocabulary

Three grounds, one accent, three severities — semantic color kept strictly separate from the accent hue. Every status carries a shape and a letter, never color alone, so it survives red night mode and color-blind eyes.

03 · Hero — Polar alignment (TPPA)

Turn the knob; watch the error fall

Three plate-solves fix the mount's true axis. Then the reticle shows exactly how far off the pole you are and which way to turn each bolt — the error vector shrinks toward center in real time as you adjust. The verdict tells a beginner when to stop: keep going, good, or excellent — stop here.

05 · For the build

How this maps to the code

Carried forward, not reinvented
  • The existing Led (shape+letter), HoldButton, Panel, Stat, brightness + NIGHT mode primitives stay.
  • Tokens above become CSS variables / Tailwind theme extensions; light + dark + .night all driven by token swaps.
  • All telemetry uses tabular-nums mono; labels are tracked small caps.
New, bound to real API
  • Provider badges ← status.providers.{autofocus,polar_align}.label.
  • V-curve + fit ← focus.points, focus.fit{method,r2,curve,trendlines}, focus.best.
  • TPPA wizard ← polar{phase,az_error,alt_error,total_error,directions} (arcmin).

Design reference for the AstroDeck native-parity UI. Spend the boldness on the two live visualizations; keep everything around them quiet. Verdict first, raw number second. Shape and letter, never color alone. The night mode is not a theme afterthought — it is the instrument's real operating mode.
