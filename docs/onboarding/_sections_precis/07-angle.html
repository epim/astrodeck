07 Rotating the Frame

Camera angle

Turning the camera in its holder sets the position angle — the rotation of the frame on the sky.

Sets
Composition — orientation of the target within the frame.
By hand
Twist the camera and lock the holder.
Motorized
A rotator drives PA to a commanded angle.
Truth
Plate-solving reports the actual PA, in degrees.

The frame rotates until the edge-on galaxy lies along the diagonal; PA settles on the plan.

Skip the angle and a mosaic's panels meet at mismatched rotations, so the seams never line up and the stitch fails.

AstroDeck shows a rotation control with planned vs. actual PA, nudging until the error closes.

It is a Dutch angle you have to justify to a plate solver.

(function () { "use strict"; var el = document.getElementById("angle-pa"); if (!el || !window.AstroAnim) return; // PA ticks from start toward the planned angle, mirroring the FOV rotation. var FROM = 168, TO = 214, DUR = 1440; // ms; ~matches the CSS rotate duration var raf = 0, t0 = 0; function ease(p) { return 1 - Math.pow(1 - p, 3); } // cubic-out, house feel function frame(now) { if (!t0) t0 = now; var p = Math.min(1, (now - t0) / DUR); var v = Math.round(FROM + (TO - FROM) * ease(p)); el.textContent = v + "°"; if (p < 1) { raf = requestAnimationFrame(frame); } } window.AstroAnim.register(el, { play: function () { cancelAnimationFrame(raf); t0 = 0; // Reduced motion calls play() once: paint the final PA, no loop needed. if (window.AstroAnim.reduceMotion) { el.textContent = TO + "°"; return; } raf = requestAnimationFrame(frame); }, reset: function () { cancelAnimationFrame(raf); t0 = 0; el.textContent = FROM + "°"; // re-arm to the starting angle } }); })();
