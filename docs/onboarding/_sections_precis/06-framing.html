06 Composing the Shot

Framing + FOV

How much sky lands on the sensor, and where the target sits inside it.

FOV
Scales as sensor size / focal length — long FL gives a tight crop.
Pixel scale
206 × pixelµm / FL mm arcsec per pixel.
Sampling
Match pixel scale to seeing; off either way wastes the data.
Big targets
Tile multiple panels into a mosaic.

A longer focal length tightens the crop; a plate-solve snaps the frame onto the target.

600 mm

Guess the FOV and the target spills past the sensor edge, or sits lost in a sea of empty sky you can't recover in processing.

AstroDeck's sky-atlas overlays the live FOV box on the target and lays out mosaic panels with overlap.

It is a viewfinder for a camera pointed at things you can't see yet.

(function () { "use strict"; // Make the focal-length slider live: the readout AND the FOV box track it. // FOV scales as ~1/focal-length, so a longer FL shrinks the box on the sky. var input = document.getElementById("framing-fl-input"); var out = document.getElementById("framing-fl-out"); var fov = document.querySelector("#framing .framing-fov"); if (!input || !out) return; var MIN = 200, MAX = 1200; // slider range, mm var BIG = 58, SMALL = 16; // box size at MIN / MAX focal length, % function sync() { var fl = +input.value; out.innerHTML = fl + " mm"; if (fov) { // inverse map: shortest FL -> widest crop, longest FL -> tightest var size = BIG * (MIN / fl); if (size > BIG) size = BIG; if (size < SMALL) size = SMALL; fov.style.setProperty("--framing-size", size.toFixed(1) + "%"); } } input.addEventListener("input", sync); sync(); })();
