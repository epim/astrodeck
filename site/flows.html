Astro Flows

Draw the night. Then go to bed.

A sequence is a list. A night is a graph. Flows lets you wire the second one directly — twenty-one node types, two kinds of wire, and a compiler that tells you what it could not honour before the mount moves.

The canvas

One graph, two lanes.

The solid lane is the night in order. The dashed lane is everything that reacts to it. They are different kinds of wire because they are different kinds of promise.

Two kinds of wire

Sequence and reaction are not the same thing.

Flow — solid

This happens, then that happens

A flow wire is an ordering promise. SLEW + CENTER emits centered and only then does AUTOFOCUS begin. The graph stays acyclic, so there is no way to draw a night that silently never ends.

Event — dashed

When this happens, do that

An event wire carries something that occurred — a graded frame, cloud arriving, an unsafe reading — to whatever should react. Events do not sequence the night; they interrupt it. Campaign loops across many nights are event wires, which is how the graph stays acyclic and a multi-night run still repeats.

Loops live inside stages, not in the graph. FILTER CYCLE is a sibling of CAPTURE LOOP, not a container: it shoots its slot table one sub per filter per pass and repeats until every slot has its count. So the channels grow evenly, and a night cut short by cloud still stacks. Forty-five L frames followed by nothing else is a mono image; one of each, forty-five times, is an image at every prefix.

A distinction worth the ink

Safety aborts and never holds. Cloud watch holds and never aborts.

These are separate node types on purpose. If one monitor did both, the fail-closed tier would beat the recoverable one to the punch every time, and the recoverable one would always lose.

Fail closed

SAFETY MONITOR → ABORT + PARK

Rain, wind, a sensor that stopped answering. A stale reading counts as unsafe, because "I do not know" and "it is fine" are not the same claim. The night ends, the mount parks, the dome closes.

Recoverable

CLOUD WATCH → HOLD / RESUME

Cloud is temporary and the hold releases itself. It keeps tracking, parks the guider, and on the way back it re-cools, re-centres with a plate solve and refocuses if HFR drifted. Give it a maximum hold and what to do if that expires.

Before the mount moves

The compiler tells you what it will not do.

A graph you can draw is not automatically a night the engine can run. Compiling reports every dropped rule on screen, by name, with the reason.

This exists because of a specific failure mode. Unknown keys are dropped in silence by default, which means a naive hand-off produces a plan that validates clean and starts a run immediately — in daylight, with no altitude gate, no dawn stop and none of the cloud rules the operator drew. Green start, wrong night, no error anywhere.

So every dropped thing is reported. You find out that your cloud rule is not running now, from a list on the screen, instead of at 3am from a mount that kept shooting through overcast.

Tier conflicts

A safety monitor also watching clouds would beat the recoverable hold every time. The doctor names it rather than letting the race happen at 2am.

Checked

Unmapped settings

Anything you configured on the canvas that the engine has no way to honour, listed before you run rather than discarded quietly.

Three shapes worth stealing

Patterns.

Pattern

The unattended single target

DUSK → TARGET → SLEW + CENTER → AUTOFOCUS → GUIDE → FILTER CYCLE → PARK + CLOSE → REPORT, with SAFETY → ABORT hanging off the side. Eight nodes and you never touch it again.

Pattern

The whole-season campaign

Swap TARGET for TARGET POOL with a quota per member, set DUSK WINDOW to repeat, and wire night ends into PARK + CLOSE. It works the list down across weeks, picking whatever is best placed each night.

Pattern

The self-correcting night

Wire frame graded into a CONDITION set to HFR above your threshold over a 3-frame window, and fire REFOCUS. Focus drift fixes itself and you find out from the report, not from the stack.

Everything on the canvas is also just a plan. Flows compile to the same sequence the engine runs when you build a night by hand, so nothing you can draw is a separate code path with its own bugs.
