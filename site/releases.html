01 / Download platforms

Match the operating system and architecture.

These are the release workflow's target names. Confirm that your chosen release includes the file and its SHA-256 sidecar before downloading.

Platform Expected executable name

macOS arm64 astrodeck-macos-arm64

02 / Build contents

Check what the build contains.

  • The standalone executable includes the browser interface and Python runtime.
  • Native guiding and native autofocus require astrodeck_native, which published releases do not include yet. Follow issue #630 for packaging status.
  • ASTAP plate solving requires the solver and its star database.
  • The Atlas has an offline schematic sky. Fetch survey tiles from inside the Atlas on your own machine before you need photographic imagery offline.

03 / Updates

Keep the update path clear.

For a standalone executable, stop AstroDeck and replace the file; its default configuration and capture directories live separately. Supervised installations have a signed update path with health checks and rollback.

The release tarball has Ed25519 signature and SHA-256 sidecars. That signature is separate from operating-system code signing for a standalone executable.
