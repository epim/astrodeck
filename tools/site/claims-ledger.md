## Source conflicts resolved in this copy

1. The release workflow still requests a DSS2 pack (now tracked as #631), but the release packager refuses to redistribute it and first boot refuses to seed it. The packager/runtime and explicit regression test control the copy. Say to fetch from Atlas, never bundled. See OFFLINE.
2. The old site advertises every native imaging provider as bundled. The release build installs the server without building `astrodeck_native`. Claude confirmed the packaging gap as issue #630. See PROVIDERS.
3. Old prose says forecast overcast vetoes dusk. The current regression tests expressly require the opposite: positive rain can veto, cloud cannot. See DUSK.
4. The old features table lists NINA dome, cover and safety monitor roles, and lacks its switch role. The current backend role tuple controls the new list. See NINA.
5. Old hardware copy lists weather stations under Alpaca. `DEVICE_CLASSES` has no ObservingConditions adapter. The new list names only registered classes. See ALPACA.
6. Old copy calls the native camera/accessory inventory proof of whole unattended nights. The new table describes the recorded checks and their limits. See HARDWARE_CHECKS.
7. The old Flow catalogue offers SLEW + CENTER and calls TARGET a single object. Current TARGET owns centring and mosaics; SLEW is retained only for saved legacy graphs. See MOSAIC.
